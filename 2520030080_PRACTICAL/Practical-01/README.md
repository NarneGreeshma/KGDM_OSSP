Procedure:

Open the Ubuntu terminal.
Create a C source file named process.c.
Write the program using fork(), execlp() and wait().
Compile the program using the GCC compiler.
Execute the program.
Enter a Linux command such as pwd, ls, whoami, or date.
Observe the Parent Process ID and Child Process ID displayed on the terminal.
Verify that the parent process waits until the child process completes execution.
