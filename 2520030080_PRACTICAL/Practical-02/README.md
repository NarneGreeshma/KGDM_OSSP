# OSSP Practical-02

## Title
File Copy Using System Calls and System Call Tracing

## Aim

To develop a C program using the system calls `open()`, `read()`, `write()`, and `close()` to copy the contents of one file to another, and to analyze system calls generated by `cat sample.txt` using `strace`.

## Objectives

- Understand file-related system calls.
- Use `open()` to access files.
- Use `read()` to read file contents.
- Use `write()` to write file contents.
- Use `close()` to close file descriptors.
- Understand user-space and kernel-space transitions.
- Trace system calls using `strace`.
- Analyze the system calls used by the `cat` command.

## Files

- `practical2.c` – C program for file copying.
- `Makefile` – Automates compilation.
- `source.txt` – Source file used for copying.
- `sample.txt` – File used for `strace` analysis.
