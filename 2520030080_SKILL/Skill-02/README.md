# OSSP Skill-02

## Title
Interactive Shell Loop and Keyboard Input Handling

## Objective

To create an interactive main loop that displays a prompt, reads user input, handles exit conditions, and manages keyboard input including backspace, Enter key, input buffering, and multi-character commands.

## Software Requirements

- Ubuntu Linux (WSL2)
- GCC Compiler
- GNU Make
- Linux Terminal
- C Programming Language

## Features Implemented

- Interactive main loop
- Shell prompt display
- Character-by-character keyboard input
- Enter key handling
- Backspace handling
- Input buffer management
- Multi-character command support
- `exit` command handling
- Empty input handling

## Testing

The program was tested with:

- Normal commands
- Multi-character commands
- Backspace correction
- Empty input
- `exit` command
